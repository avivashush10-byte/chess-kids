# ממלכת השחמט

אפליקציית ווב שמלמדת ילדים (גילאי 6–8) לשחק שחמט: שיעורים קצרים עם הקראה בעברית, משחקונים, חידות ומשחק מלא מול המחשב או מול חבר.

אין שלב build ואין תלויות – HTML, CSS ו-JavaScript רגילים.

- הרצה מקומית: `node server.js` ואז http://localhost:3240
- בדיקות (חוקי המשחק + כל התרגילים פתירים): `node tools/validate.js`
