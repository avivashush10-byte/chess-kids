# ממלכת השחמט

אפליקציית ווב שמלמדת ילדים (גילאי 6–8) לשחק שחמט: שיעורים קצרים עם הקראה בעברית, משחקונים, חידות ומשחק מלא מול המחשב או מול חבר.

אין שלב build ואין תלויות – HTML, CSS ו-JavaScript רגילים, ושרת Node קטן.

- הרצה מקומית: `node server.js` ואז http://localhost:3240
- כל ילד נכנס בשם שלו; ההתקדמות נשמרת במכשיר, ואפשר לסנכרן בין מכשירים עם קוד משפחה (אזור ההורים). הכללים: [SYNC.md](SYNC.md)
- שרת הסנכרון בענן: `render.yaml` (Render + Upstash). הכתובת שלו נרשמת ב-`js/config.js`.

## בדיקות

- `node tools/validate.js` – חוקי המשחק, וכל תרגיל וחידה פתירים
- `node tools/test-store.js` – שמירת ההתקדמות לכל ילד
- `node tools/test-sync.js` – כללי המיזוג והשרת (על קובץ זמני ו-Upstash מדומה)
